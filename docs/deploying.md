# Deploying

The site is served at [mhfu.vallode.com](https://mhfu.vallode.com), randomfu's web app at [randomfu.vallode.com](https://randomfu.vallode.com) and Whetstone's at `whetstone.<subdomain>.workers.dev` until it has a custom domain, all from Cloudflare. Each is a Cloudflare Worker serving static assets, configured by `apps/blacksmith/wrangler.jsonc`, `apps/randomfu/wrangler.jsonc` and `apps/whetstone/wrangler.jsonc`; Whetstone's has no script. The site's Worker also runs a script, `apps/blacksmith/src/cloudflare/worker.ts`, for the set builder's pages and share links only: it serves a shared set's link (`/sets/<code>/<name>/`) the set builder's page, and gives it its own embed by rewriting the page's meta tags, with the set's skills and stats and an image of the set drawn as a card (`/set-builder/card.png`, rendered with satori and resvg and kept in Cloudflare's cache). Every other request is a static asset request that never runs it.

Cloudflare's Workers Builds deploys them from this repository: a push to `main` builds and deploys the site it changes, and the build's result shows up as a check on the commit or pull request. Its settings (root directory, build command, build variables such as `NEXT_PUBLIC_SITE_URL` and `SITE_URL`, watch paths) are in the Cloudflare dashboard, under each Worker's Settings > Build.

To deploy by hand from GitHub Actions instead, run the **Deploy to Cloudflare** workflow (Actions > Deploy to Cloudflare > Run workflow), choosing the branch and the site. It builds the site in GitHub Actions and uploads it with Wrangler. `main` deploys to production at `<worker>.<subdomain>.workers.dev`, plus any custom domain added to the Worker in the Cloudflare dashboard. Any other branch gets a preview URL named after the branch, `<branch>-<worker>.<subdomain>.workers.dev`, once `main` has been deployed. The workflow needs the `CLOUDFLARE_API_TOKEN` (made from the "Edit Cloudflare Workers" template) and `CLOUDFLARE_ACCOUNT_ID` repository secrets. The `BLACKSMITH_URL`, `RANDOMFU_URL` and `WHETSTONE_URL` repository variables set a site's production address for its link previews once it has a custom domain.

Cloudflare's free plan takes at most 20,000 files per deploy, and the site's `out/` is close to that (about 19,700). Past it, deploys fail until the account is on the Workers Paid plan (100,000 files).
